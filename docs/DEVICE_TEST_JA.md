# 実機検収（未実施）
Android6 Z3TC / Android7 Z4T / Android8 XZ1 Compactを優先。Android9/10実機は未確保。API23/24/26/28/29のCIエミュレータで、2006/2038作成・全画面白黒・四隅・時計領域タップ透過・停止は検証済み。エミュレータ成功を実機合格と扱わない。

1. インストール後、重ねて表示を拒否→安全に開始できないこと。許可して開始。
2. 白/黒の全画面確認で時計と縦型電池の影、配置、タップで戻れること。端付近を含めゲームのタップ/スワイプが通ること。
3. 通常バー/没入型/透明バー、縦横回転、ナビバー、切り欠き。二重化・クリップを確認。全画面のみは誤判定時にOFFへ。
4. 時計/電池それぞれOFF、充電開始/終了・残量、時刻/タイムゾーン変更。上/下角丸・半径0・最大を確認。
5. アプリ別「なし/上/下/両方/共通」を設定。使用状況許可なし→共通、許可→1秒程度で切替。許可を取り消すと共通へ戻ること。
6. 消灯→復帰、タスク終了、再起動、長時間放置、低メモリ、省電力制限。停止操作後は再起動しても開始しないこと。
7. 表示中の重ねて表示権限取消→安全停止。互換方式2038ではバー領域が背面になること。

消灯時CPU/常駐メモリ・APKサイズは計測結果と区別する。Android11以降は保証外。target25のため新OSのインストール制限・警告はあり得る。ストア公開を対象にしない。
