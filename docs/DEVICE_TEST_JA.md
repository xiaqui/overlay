# 実機検収

電池仕上げ版0.7.0は [BATTERY_FINISH_JA.md](BATTERY_FINISH_JA.md) の3方向・独立4調整・柔らかい外側影の検収を追加する。自動試験63件の成功と実機外観合格は別。旧設定移行・初期値復帰・端子/残量/充電、時計の位置不変を優先する。

Navbar技術検証版の検収は [NAVBAR_PROTOTYPE_JA.md](NAVBAR_PROTOTYPE_JA.md) の実機検収節を追加で実施する。
まず着色OFFで以下の既存検収、次にNavbar Apps停止・縦画面3ボタンで着色/黒い下隅/全ボタン/
没入型での消去を確認する。XZ1 Compactを最優先。エミュレータ合格は実機合格ではない。

初版の基本機能はXperia実機で良好とのユーザー報告あり。Issue #4変更後の以下の実機検収は未実施。Android6 Z3TC / Android7 Z4T / Android8 XZ1 Compactを優先し、Android9/10も確認する。CIの結果と実機合格を混同しない。自動試験の正確な結果・対象SHAはWORK_PROGRESS.mdに記録する。

1. 既存版の上へ新APKをインストールでき、設定と署名の互換性が保たれること。旧アプリ別「なし」は「なし」、旧「上/下/両方」は「通常」へ移り、全体の上/下ON/OFFと半径は保持されること。未設定アプリは「通常」。
2. 「全画面のときだけ」をON。通常の不透明ステータスバーと透明ステータスバーでは時計・電池を非表示、没入型とstatusのみ非表示では表示。通常→全画面→通常、アプリ切替、縦横回転を繰り返し、約500ms後の状態とちらつきを確認する。
3. 常時表示モードでは通常/全画面とも表示されること。自動判定が機種固有で合わない場合、使用状況アクセスを許可し、別UIの「全画面判定のアプリ別例外」で表示/非表示を指定できること。常時表示モードはこの例外で消えないこと。許可を取り消すとアプリ別指定が適用されないこと。
4. アプリ別角丸の選択肢が「なし / 通常 / 上だけ内側 / 下だけ内側 / 上下とも内側」の5個だけであること。「なし」は非表示、「通常」は四隅、「上だけ内側」は上2隅のみstatusの下、「下だけ内側」は下2隅のみnavの内側、「上下とも内側」は両方。全体の上/下ON/OFFと半径0/最大も確認する。
5. バーを隠すと該当する角丸offsetが0になること。縦横回転でナビが下/左/右へ移る場合の位置、3ボタン/2ボタン/ジェスチャー方式を利用可能な実機で確認する。IME表示で角丸がキーボード上へ飛ばないこと。
6. 一時的にスワイプ表示するtransientバーはOSが観測窓へ可視状態を反映しない場合がある。切り欠きのある端末は上下左右どの辺でもunknownとし、時計・電池を表示維持、角丸offsetを0とする制限がある。自動判定の完全対応とは扱わず、必要なアプリへ例外を設定する。
7. 白/黒背景で時計・横型電池・右下方向の細い黒影・既定の右上配置が読めること。数字1/7/0/3、残量20/50/80%、充電中を重点確認する。
8. 消灯→復帰、タスク終了、再起動、長時間放置、低メモリ、省電力制限。停止後は再起動しても開始しないこと。表示中に重ねて表示権限を取り消すと安全停止。拒否状態で開始できないこと。
9. 旧2006方式が拒否され2038へフォールバックした場合、互換方式ではシステムバーより背面となる制限を確認する。旧2006方式でもOSのレイヤー規則により可視バーが角丸より手前になる場合があり、「通常」の物理端への配置とバー上に見えることは区別する。
10. 時計配置の既定が「右」で従来と同じ電池＋時計の並びになること。「左」では時計だけが左上、電池だけが右上へ移り、個別OFF、負数位置、特大文字、縦横回転、通常/没入型でもタッチが下へ通ること。
11. 電池方向の既定が「通常（端子右・左から増加）」で旧表示と同じこと。「反転」では端子左・右から増加となり、充電マークも鏡像になること。Z3TCの純正表示との一致は実機画像で判定し、Android 6全機種へ一般化しない。
12. 「全画面判定のアプリ別例外」が旧3択に「時計のみ表示」「電池のみ表示」を加えた5択であること。両方の全体ON/OFF、全画面/通常画面、アプリ切替、回転、消灯復帰、使用状況アクセス取消を確認する。全体OFFの要素が部分表示例外で復活しないこと。消灯復帰の自動試験はAPI24〜29で行い、API23エミュレータは復帰不能で後続試験を停止するため、Android 6はZ3TC実機で検収する。
13. 時計のみ／電池のみ／両方非表示へ切り替えた際、不要な透明窓が操作を遮らず、通常アプリへ戻ると自動設定どおり復元すること。

消灯時CPU/常駐メモリ・長時間消費電力は未計測。Android11以降は保証外。target25による新OSの制限やストア配布は対象外。
