# Overlay 製品仕様（初版）
更新: 2026-10-21

## コンセプト
Android 6〜10向け・Xperia最優先。必要なものだけを静かに画面へ重ねる軽量アプリ。多機能化や独自デザインは目的としない。

## 確定機能
### A. 浮遊時計
- OS標準の時計と同じ表示位置・文字サイズ・色・雰囲気。画面全体は覆わない。
- ステータスバーが消える全画面アプリでも表示することが最重要。
- 白い背景で文字が埋もれないように薄い黒影（または極細アウトライン）。背景プレート不要。
- ON/OFF。常時表示と全画面時のみを候補にし、機種ごとの成立を検証。
- OS時計と二重化する状況を抑え、必要に応じて手動の調整手段を残す。

### B. バッテリー表示
- Xperia標準のバッテリー形状を優先し、残量が正しく反映されること。
- 時計と同様の位置・透過・明背景での影・全画面表示。
- 時計とは独立ON/OFF。
- 数値%はOSの標準挙動に近づけ、デザイン機能を増やさない。

### C. Round Corners
Issue #4の最新コメント6298032616で更新。アプリ別は「なし / 通常 / 上だけ内側 / 下だけ内側 / 上下とも内側」の5択。上/下は表示範囲でなく現在のシステムバーを避ける描画位置。未設定は通常。非表示バーのoffsetは0。詳細はISSUE4_JA.md。
- 黒い角丸のみ。装飾・アニメーション・テーマは不要。
- 角丸半径、上/下を設定できる。
- **アプリごとに** 角丸の非表示/通常/上下の内側配置を指定5択で切り替えられる。全体の上/下ON/OFFは保持する。
- ステータスバーとナビバーを含む画面上下のどちら側に描画できるかはAndroidの制限を検証し、設定UIで実際に可能な範囲を明確にする。

## 初回の外観合わせ
ユーザーの許可を取ってスクリーンショットから標準UIの位置・サイズ等を推定できれば理想。これをMVPの絶対条件にはしない。端末メーカー差は手動位置調整をフォールバックとし、スクリーンショットを外部送信しない。

## 表示／操作の原則
- 時計・電池は通常タッチ透過。余計な常時再描画をしない。
- 表示する各オーバーレイは必要最小の矩形で実装し、ステータスバーやゲーム操作を邪魔しない。
- 権限取得・常駐通知はOS要件に合わせて最小限。
- Android 6/7/8/9/10を対象に差異を吸収し、Android 11以降は保証外のベストエフォート。
- 新しいAndroidでのインストール可否やtargetSdk制限も明記する。

## 参照資料（動作・見た目の参考でありコード流用の許諾ではない）
- 浮遊時計: com.psc.fukumoto.FloatClock、提供APK 1.1.5 (versionCode 16)
- バッテリーメーター・オーバーレイ: jp.gr.java_conf.soboku.batterymeter、提供APK 5.7.0 (versionCode 570)
- Round Corners: com.bhanu.roundcorner、提供APK 2.9 (versionCode 19)
- ユーザー提供の明背景スクリーンショット: 画面右上の電池と23:46の見え方が基準。スクリーンショット自体はGitHubへ転載しない。
- 実機情報: 既存の浮遊時計がAndroid 8以降でも所望の位置へ表示できている。一般論で否定せず再現方式を調べる。

## 非目標
アプリ独自の派手な時計、電池テーマ、角丸の装飾、広告、分析SDK、通信処理、クラウド同期、ブルーライトフィルター、エッジジェスチャー。
