# 設定階層とアプリ別上部情報（PR #35 C〜H）

- 起点 main: `c2189b266860a3d86b56cb8621d88a186f0adb46`（#37、#39 を含む）。仕様: #35 の head `ef2bf3c17c795c72c16b19511d5dbbdf6a1721fb`。この実装PRでは署名・配布・マージを行わない。
- 全体停止中も編集可。ナビバー着色OFFでは上下同色・Recents設定を無効化し、角丸OFFでは半径を無効化。いずれも設定は消さない。旧片側角丸は初回に変更せず、見出しスイッチを明示操作した時点から上下を一括設定する。
- 全画面限定は未保存時のみON。保存済みの明示ON/OFFは変更しない。上部情報の自動判定はこのスイッチに従う。常に表示／表示しないは全画面限定のON/OFFを問わず適用する。どちらも全体停止や時計・電池の個別「なし」を上書きしない。
- 旧表示値0/1/2は自動判定／常に表示／表示しないに対応し、3/4は自動判定へ戻す。他の個別上書きを維持し、すべて既定のアプリは設定済みとしない。
- 設定の切替は既存Viewを局所更新する。同じ画面の操作ではScrollViewを置き換えない。画面復帰・再生成時に先頭から表示する #37 の方針は維持。従来のXperia Home候補を維持。

## Z3TCの上部バー

#35の固定白の報告では上下の指定色、上側の描画到達、実座標が揃っているが、上側は実画面では暗い青灰色のままだった。コード上、Android 6の上側は TYPE_PHONE (2002)、下側は既存の TYPE_SYSTEM_OVERLAY (2006) で別窓。ready/描画回数と最終合成は別であり、実機証拠なしにSystemUIによる遮蔽と確定しない。Z順やWindow種別は変更せず診断を維持する。

## 実機検収

1. 旧版から上書きし、明示の全画面設定、片側角丸、半径、時計・電池の配置・寸法・位置、固定色・無着色の保持を確認。旧3/4だけ自動判定へ戻ることを確認。
2. Android 6〜10で特大文字・回転・権限画面往復、アプリ別ダイアログ、Xperia Home、操作中のスクロールと反応を確認。
3. 縦横・全画面・通常・Recentsで各アプリ設定と停止／再開を確認。Z3TCではChrome固定白とNoRoot Firewallで上下の見え方と診断を比較し、OSアイコン・ナビボタン・タッチを確認する。
