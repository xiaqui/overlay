# 画面表示仕上げ 実装・検収手順（2026-10-23）

## 実装方針

- 位置: `x` / `y` の保存形式は従来の整数dpのまま、調整範囲を `-64..100 dp` へ拡張した。既存値と初期値（x=4、y=0）は変更しない。読み出し時も範囲内へ丸めるため、異常な旧値で完全に見失っても設定画面から復旧できる。
- 大きさ: 保存済み `size` は基準spとして解釈し、`scaledDensity` に含まれるOS `fontScale` を1回だけ適用する。手動値へ別の倍率を重ねない。電池寸法も同じ実効文字サイズから算出する。
- 電池: 独自Canvas描画を横長（本体幅0.94×文字高、本体高0.56×文字高）へ変更し、端子を右側へ配置した。残量は左から右へ比例表示し、充電マークも維持する。
- 影: 時計と電池を半径0.55dp、右0.55dp・下0.65dp、黒alpha B8の同一パラメータに揃えた。白地で輪郭を残しつつ、元祖浮遊時計に近い右下方向の細い影として太い縁取りを避ける。
- アプリ別着色: `自動 / 固定色 / なし` を区別する。旧 `navbar:<package>` はそのまま固定色として解釈する。「なし」は色・透明Navbar帯を描かずNavbar着色窓を外し、従来の角丸窓へ戻す。上下統一ONでも上側の事前登録済み1×1待機窓を無描画のまま維持し、着色領域へ拡大しない。明示的な「なし」をRecents一時停止より先に解決する。未設定は従来どおりグローバル自動設定へ従う。

新規Service、poll、権限、通信、ライブラリは追加していない。角丸5状態、上下統一着色、Recents停止、全画面判定、タッチ透過の処理は維持する。

## 自動確認範囲

- 設定: 負数の保存・復元、範囲外値の安全な丸め、旧固定色データの互換、3状態遷移。
- 描画: fontScale 1.0→1.5での測定高増加、横長電池、右側端子、白背景に残る暗い輪郭。
- 統合: アプリ別「なし」で上下着色が停止し、固定色へ戻すと復元すること。
- 回帰: 既存のAPI23/24/26/28/29 instrumentationで角丸、上下着色、Recents、全画面、回転、権限取消、タッチ透過を再確認する。

## Xperia実機検収（自動試験とは別）

1. 旧版から上書きし、既存の角丸・固定色・表示例外が残ることを確認する。
2. Z3 Tablet CompactでOS文字サイズを標準／特大に切替え、Overlay再構成後に時計と電池が一緒に拡大すること、手動サイズ値が変わらないことを確認する。
3. 白い漫画起動画面と黒い全画面を開き、時計の細い黒影、横電池の枠・残量・右端子が潰れず読めることを撮影比較する。
4. x/yを負数へ動かして元祖浮遊時計に近い右上位置へ寄せ、回転・画面OFF/ON後にも復元することを確認する。欠けた場合は0へ戻して復旧する。
5. 固定色のあるアプリを「なし」へ変更し、上下バーがアプリ本来の表示になる一方、角丸・時計・電池が残ることを確認する。自動・固定色へ戻した際の復元、Recents停止も確認する。
6. Android 6/7/8/9/10の優先5端末で、通常／没入型、回転、上下バー表示・非表示を確認する。
