- [ ] **既存の「電池の向き」設定に縦型を追加する（手動サイズ・位置調整と同一の次期表示仕上げ）**。
  - 現状は横型の「通常（端子右）」と「反転（端子左）」の2択。端末の純正表示は縦型の場合もあるため、設定メニューを **「横（端子右）／横（端子左）／縦（端子上）」の3択**に拡張する。単に画面の縦横回転から自動判定する仕様ではない。
  - **既定は現行どおり「横（端子右）」**。既存の `battery_reversed=true` は「横（端子左）」へ移行し、既存利用者の表示が勝手に縦型へ変わらないようにする。新規の向き保存方式と古いキーの優先順位・移行をテストする。
  - 縦型は端子を上に配置し、本体・端子・残量・充電マーク・シルエット影を一貫した縦型形状にする。残量は下から上へ増える。線幅・端子の比率、充電マーク・暗い影の輪郭が回転で崩れないこと。
  - 向きが変わっても **電池専用サイズ・横位置・縦位置を共通設定**として適用し、縦横比は各形状で保持する。時計の文字サイズ・配置は変更せず、時計右寄せでも電池の縦型化によって時計が押し出されたり重ならないようレイアウトを再計算する。
  - 全3方向と残量0/20/50/80/100%、残量不明、充電中、白黒背景、時計左／右、アプリ別「電池のみ」表示、画面回転、旧版からの更新を回帰する。設定画面から必ず元の横型に戻せること。
  - OSバージョン・機種名で向きを決め打ちせず、実機を見ながら手動で選ぶ。エッジジェスチャー・拡大鏡は別件。

- [ ] **電池アイコンのサイズ・位置を、時計とは独立して手動調整できるようにする（最優先の次期表示調整）**。
  - 複数端末の純正ステータスバーとの比較で、電池の大きさ・右端／上端からの距離が一致しない。機種・OS別に固定値で決め打ちせず、**ユーザーが実機を見ながら合わせられる方式**を採用する。
  - 設定画面に **「電池サイズ」「電池の横位置」「電池の縦位置」** の3つの調整スライダーを設ける。時計の既存「文字サイズ」「左右の端からの距離」「上端からの距離」は引き続き時計側で使用し、電池側の変更では時計の大きさ・位置が動かないこと。
  - 電池サイズは元の縦横比、端子、本体・残量・充電マーク・シルエット影の相対比率を維持して一体拡大縮小する。位置は上端・右端からのオフセットをdp単位で調整し、必要なら負数を許す。時計が右寄せの場合も電池位置・サイズを独立して動かせる設計とする。
  - **旧版から更新した場合は新しい補正量を0（サイズは現行相当）とし、見た目・保存済み設定を変えない**。時計と電池を分離することで、従来の右寄せ時の間隔や配置がずれないよう移行・レイアウト計算をテストする。
  - 左時計＋右電池、右時計＋電池、時計のみ、電池のみ、通常／反転、OSのfontScale、縦横回転、白／黒背景、残量20/50/80%、充電中を検証する。時計と電池が重なったり画面外に出たりする極端値には、設定画面から復旧できる手段（初期値に戻す等）を用意する。
  - 小さな非タッチ窓による透過性、不要ウィンドウの削除、従来の軽量性を維持する。画面取得・アクセシビリティ等の新規権限や新機能を混ぜない。
  - 提供されたゲーム画面2枚は純正／Overlay比較の**参考**として使うが、添付画像が作業環境で自動的に参照できるとは限らない。現物なしで数値を決め打ちせず、表示確認用白／黒プレビューと社長の実機調整で最終受入する。
  - 作業時にTASKへ明示して**専用の小さなPR**で実装・テスト・独立レビュー。新機能（エッジジェスチャー／拡大鏡）より先に実施する。
