# 設定画面整理・アプリ別設定統合

仕様整理PR #28を基に、実装PR #29で5パートへ整理した。描画・全画面・Recents判定・電池幾何は変更せず、Navbar着色ON時の自動推定標準化だけを変更する。

## 設定互換性

- 時計/電池のON/OFFは従属UIだけを隠す。サイズ・位置・比率・方向の保存値は変更しない。
- 電池初期値復帰ボタンはUIから削除。削除時のリセット/移行処理はない。
- 上下角丸OFF時は半径、Navbar OFF時は上下同色/Recents設定を隠す。復帰時は保存値を読む。
- `navbar_auto`の旧保存値は残すが判定に使用しない。固定色→自動テーマ/アイコン推定の順。アプリ別「なし」は自動推定より優先して無着色。
- 既存corner2/display/navbar/navbarModeのキーをそのまま使用。設定済みのインストール済みアプリはランチャー入口がなくても一覧へ含め、先頭に並べる。
- 使用状況アクセス未許可でも設定編集は可能。適用不可の理由と権限設定導線を表示する。
- 主画面再構築時とActivity状態保存時にスクロールYを保持。内容が短くなる場合はScrollViewの有効範囲へ収まる。

## 自動試験と限界

SettingsUiTestは実Activityの5区分、時計/電池/角丸/Navbarの条件付き表示と値保持、スクロール復元、設定済み非ランチャーアプリの一覧モデルを検査する。NavbarTestは旧自動OFFでも固定色削除後に自動推定へ戻ることを待機し、画素確認する。既存の描画・窓・権限・全画面回帰試験も継続する。

一覧モデルの試験は、アプリ別ダイアログの実タップ・固定色入力・キャンセル・権限画面往復の検収とは異なる。これらの保存キーとキャンセル無書込は静的確認済みだが、以下の操作受入は未実施。エミュレータ合格をXperia実機合格とは扱わない。

## 実機検収（Android 6〜10）

1. 旧版で時計/電池のサイズ、負数位置、比率、方向、左右、角丸、アプリ例外、固定色/なしを記録し上書き更新。すべて一致すること。
2. 時計/電池を各OFFにして調整欄だけ消えること、ONで値と表示が復元すること。電池リセットボタンがないこと。
3. 上下角丸OFFで半径欄だけ消え、ONで半径が復元すること。
4. Navbar OFFで2つの従属スイッチが消え、ONで保存状態が復元すること。旧auto=falseでも通常アプリは推定色、固定色優先、「なし」は無着色となること。
5. アプリ別設定の入口が1つで、設定済みが先頭になること。同じアプリ画面で角丸5状態・表示5状態・固定色/自動/なしを編集。固定色入力をキャンセルして以前の値が保たれること。
6. Usage Access未許可でも保存済み設定を確認/変更でき、適用不可の短い理由が出ること。許可後の前面切替で反映すること。
7. 下方へスクロールしてON/OFFや選択変更、画面回転、外部設定画面往復を行い、不必要に先頭へ戻らないこと。特大文字で操作・ダイアログ内スクロール可能なこと。
8. 詳細画面だけに互換方式/診断があり、通常・全画面・Recents・画面OFF/ON・白黒・タッチ透過・既存角丸/時計/電池が従来どおりであること。
