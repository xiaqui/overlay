# Overlay Apps
Android 6〜10 / Xperia向けの軽量時計・電池・黒い角丸。通信・広告・分析SDKなし。

Navbar技術検証版（初期OFF）: アプリ別固定色／任意のテーマ・アイコン推定色を既存Serviceへ追加。
着色帯と黒い下隅は同じCanvasで描画します。縦画面・3ボタンが対象で、Xperia実機の成立は未検証です。
方式・配送記録・実機検収・正式統合の判断基準は [docs/NAVBAR_PROTOTYPE_JA.md](docs/NAVBAR_PROTOTYPE_JA.md) を参照。

初回は「重ねて表示」を許可し「表示を開始」。画面右上に時計とXperia風の横型電池を表示します。OS文字サイズ、基準sp、-64〜100dpの上端・右端距離、白/灰色を調整できます。黒い角丸は上下独立、アプリ別に「なし / 通常 / 上だけ内側 / 下だけ内側 / 上下とも内側」を選べます。未設定は通常です。バー着色もアプリ別に「自動 / 固定色 / なし」を選べます。前面アプリに応じた着色・アプリ別設定の適用には使用状況アクセスが必要です。未許可時は説明からOSの設定へ進めます。「後で」でもアプリ別設定の編集・保存は可能です。消灯中はタイマーを停止します。

全画面のみ表示は通常/透明バーと没入型を観測して切り替えます。機種固有の挙動、一時表示バー、切り欠きには制限があり、アプリ別の表示/非表示例外を用意しています。標準は旧ウィンドウ方式（targetSdk 25）、拒否時はAPI26以降で2038にフォールバック。互換方式はステータスバー・ナビバーより背面になります。root・adb権限・非公開APIは使いません。Android11以降およびストア配布は対象外です。

設定画面の白/黒の全画面確認で、影とタッチ透過を検収してください。実機未検証事項は docs/WORK_PROGRESS.md と docs/DEVICE_TEST_JA.md を参照。

ビルド: Java17 / Gradle8.7 / Android SDK35。`gradle testDebugUnitTest lintDebug assembleDebug`。署名は既存KEYSTORE_* SecretsをActionsに渡し、mainでテスト・署名照合・再ダウンロード検証後にGitHub prereleaseへ直接配布。Artifactアップロードは使いません。秘密鍵・参考APK・ユーザースクリーンショットはリポジトリに含めません。

Issue #4修正: アプリ別角丸は「なし / 通常 / 上だけ内側 / 下だけ内側 / 上下とも内側」。未設定は通常、全体ON/OFFは維持。全画面判定・バー内側配置はInsetsを観測し、機種で合わない場合の時計/電池のアプリ別例外を用意。制限・旧設定移行はdocs/ISSUE4_JA.md、検証状況はdocs/WORK_PROGRESS.md。
